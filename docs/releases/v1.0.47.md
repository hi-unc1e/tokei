# v1.0.47

- 用量卡片默认按当前时间范围的 Token 总量从高到低排列，无需额外筛选。
- Windows 使用可缩放的主窗口，支持最小化、最大化和任务栏入口；手动启动及再次打开应用会显示主窗口，托盘保留快捷面板和打开主窗口的入口。
- Windows 补齐应用活跃统计开关、Claude CLI 额度查询、Grok Bot 授权；额度查询按设置启用，授权和隐私选择在本机保留。
- Windows 的 Grok Bot 历史统计按已授权账号隔离；Claude CLI 只更新实际返回的额度窗口，保留其他窗口原有的过期状态。
- Windows 首次加载先呈现界面和本地用量，再更新额度；后续启动可立即显示当天的用量预览，并标注原数据时间。其他页面与语言按需加载，减少首屏体积。
- 修复 Windows 额度详情刚写入快照时，因文件时间的微小精度差异触发重复采集的问题。
- 修复 Windows Grok 日志原地改写、大小和时间戳相同时未更新用量缓存的问题。
- 加强 Windows 千问办公额度配置读取，拒绝符号链接及打开过程中被替换的配置文件。
- 修复 Mac 用量卡片刷新后重复显示平均输出速度、TTFT 等指标的问题，并统一检查 Windows 卡片的动态指标标识。
- Pi 速率优先使用日志提供的请求耗时与首字计时；缺少首字计时的记录明确标注“含等待”。平均速度继续按总输出 Token 除以总计时时长计算。
- 修复偶数样本 TTFT 中位数跨直方图桶时偏向较小值的问题，采集器与 Mac 多设备合并使用一致算法。直方图中位数仍为近似值。
- 包含自上一正式版以来的模型定价与展示修正，以及其他稳定性改进。

- 完善 Windows、macOS、Linux 全量回归，修正平台与 Python 3.12 的测试兼容问题；全量测试通过后才构建 Windows 安装包。

安装包：macOS 通用 DMG 同时包含 Apple Silicon 和 Intel；Windows x64 安装包内置 Python。
